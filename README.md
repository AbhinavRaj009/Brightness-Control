In this article, we are going to make a Python project that uses OpenCV and Mediapipe to detect hand gestures and accordingly set the system's brightness from 0 to 100. 

What is Brightness🔆 Control Using Hand Gesture?

1. It uses hand✋ gestures captured by a camera📷, recognized and translated into corresponding commands to control the volume and brightness settings. 
2. It can be particularly beneficial when manual control🕹️ is not feasible or desired, such as when the user is handicapped or old people👵🏻.
3. By leveraging computer vision techniques and machine learning algorithms, hand gestures captured by a camera are
   recognized and translated into corresponding commands to control the volume and brightness settings.
4. We have used a hand-tracking module that tracks all points on the hand and detects hand landmarks.
5. It calculates the distance between the thumb tip and the index fingertip and maps the distance between the thumb tip and the index fingertip with brightness range.
